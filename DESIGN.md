# SubletSqk

An independent Squeek rental neighborhood, not an official Squeekchain property.

Near-black canvas, warm white type, lilac secondary accents and warm sunflower yellow actions. The original hamster-key mark uses mint (#83F5CD) and coral (#FF806C), rounded geometric shapes, a wink, hamster teeth, and a key-shaped tail. It preserves the hamster connection to Squeek while using a distinct vector style. The Sqk portion of the wordmark is mint. Space Grotesk headings and DM Sans body text. Spacious product layout, precise rules, modest radii and thin borders. No invented metrics or listings.

References reviewed: VoltAgent awesome-design-md Linear analysis (dark surfaces and hierarchy); UI UX Pro Max design-system search for NFT marketplace/playful/dark (purple/gold, explicit transaction feedback, keyboard focus, reduced motion); React Bits Plasma (vendored TypeScript/CSS) provides a warm flame/wave background across public marketing pages. The application uses a separate quiet surface.

Reduced motion, clear transaction confirmation, form labels, exact SQK approval, visible compatibility limit before rent, empty/error/loading states and responsive layouts are required. NFT artwork must come from tokenURI and render as an isolated image. Decorative branding is never represented as a real NFT listing.

Public top navigation: Home, How it works, Docs, FAQ. Launch app enters /app/. App top navigation: Explore, My Squeeks, My Rentals, Earnings, Docs. Every destination has its own URL. The project wordmark remains SubletSqk with no trailing dot. Public documentation uses top topic navigation, with no sidebar.
