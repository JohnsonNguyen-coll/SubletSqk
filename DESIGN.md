# SubletSqk

An independent Squeek rental neighborhood, not an official Squeekchain property.

Near-black canvas, warm white type, lilac secondary accents and warm sunflower yellow actions. Dot-grid hamster-house mark is original vector art inspired by the supplied Squeek visual language. Space Grotesk headings and DM Sans body text. Spacious product layout, precise rules, modest radii and thin borders. No invented metrics or listings.

References reviewed: VoltAgent awesome-design-md Linear analysis (dark surfaces and hierarchy); UI UX Pro Max design-system search for NFT marketplace/playful/dark (purple/gold, explicit transaction feedback, keyboard focus, reduced motion); React Bits DotGrid (vendored original TypeScript/CSS, used only in the hero).

Reduced motion, clear transaction confirmation, form labels, exact SQK approval, visible compatibility limit before rent, empty/error/loading states and responsive layouts are required. NFT artwork must come from tokenURI and render as an isolated image. Decorative branding is never represented as a real NFT listing.
